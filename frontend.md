# Middle/Senior Frontend-разработчик React + TypeScript (удалёнка)

Мы активно развиваем интерфейс и внутренние инструменты, постоянно добавляем новые фичи — и ищем разработчика, которому интересно влиять на архитектуру и качество продукта.

#### Технический стек

Мы разрабатываем одностраничное приложение (SPA) на TypeScript + React 18.

В стеке:
- Redux Toolkit + RTK Query — для работы с состоянием и API
- React Router v6 — маршрутизация
- React Hook Form — управление формами
- SCSS-модули — стилизация
- Storybook — изолированная разработка и ревью компонентов
- Собственный UI Kit, поддерживаемый по макетам из Figma
- Webpack — сборка фронтенда

Легаси-кода нет: весь проект ведётся на актуальных версиях библиотек и с единой архитектурой. Компоненты проходят ревью на раннем этапе через Storybook, прежде чем попасть в основной продукт.
